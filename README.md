## 👤 About Me

<img align="right" width="380" src="https://github.com/user-attachments/assets/c2c7109c-4b0f-438d-8b63-9c10a61d2370" alt="Elvis Odihiri - Cloud Engineer" />

I'm an IT professional specialising in **Microsoft cloud identity and infrastructure engineering**, with hands-on experience building enterprise-grade lab environments that mirror real-world production scenarios.

My work centres on the Microsoft stack — from on-premises **Active Directory** through to **Microsoft Entra ID**, Conditional Access, Privileged Identity Management, and hybrid identity architectures.

Currently preparing for **SC-300** and **AZ-104** certifications, with a portfolio of structured lab projects designed to demonstrate senior-level engineering capability.

**What I build:**
- Enterprise identity pipelines with Entra ID & AD DS
- Hybrid identity environments with Entra Connect
- Zero Trust security models with Conditional Access
- Automated identity workflows using PowerShell & Graph API
